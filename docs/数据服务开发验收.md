# 数据服务修改与验收

依据：用户提供的《数据服务_codes.docx》。开发日期：2026-10-03。

## 页面与流程

- 主导航只保留「数据服务」一个入口。原子页面地址重定向到相应内部页签。
- 企业端包含数据产品、场景应用、我的授权、我的订阅。平台端增加授权审核与产品管理。
- 产品以卡片展示；详情包含介绍、字段、格式示例、应用场景、服务约定和额度版本。
- 企业填写部门、应用、用途、场景、期限与数据范围，确认后提交申请。申请企业取当前登录主体。
- 平台审核通过后生成对应版本的授权；企业可开通 API 或文件订阅，管理调用额度、暂停、恢复、取消与凭证轮换。
- 申请支持撤回、退回后重新申请；授权与产品到期、暂停、下架或版本改变后停止相关调用。
- 场景应用关联运输规划、全程跟踪、承运合作评估和通道风险监测，并链接现有业务页面。

## 五类产品与业务口径

| 产品 | 当前业务来源 | 输出与限制 |
| --- | --- | --- |
| 多式联运运力资源 | 已发布且有效的运输供给、承运履约记录 | 限授权起讫城市；运量范围、装载形式、运输方式、运价区间；承运主体脱敏；不提供联系方式、合同底价与精确报价 |
| 粮食物流通道运行态势 | 合同对应联运业务、运输阶段、有效公共态势登记 | 按日、周、月汇总；以大运单计量，跨运输阶段不重复计吨；不足3单隐藏吨数和效率；无单运单与企业明细 |
| 联运链路核验追溯 | 本企业指定运单的运输阶段、执行事件、节点观测与回传记录 | 每次传入明确获授权运单号；标准化事件与一致性标识；结构化证据分类；不提供原始单据图片，不开放批量枚举 |
| 承运主体信用画像 | 承运履约、异常及结算记录 | 近3或12个月；准时、异常、结算与样本统计；主体脱敏；少于3单不评级；仅用于合作参考 |
| 运输风险预警专题 | 有效公共态势、本企业在途任务的风险记录 | 公共通道风险与本企业运单风险；级别、可获得的影响时长与建议；支持 API、文件和风险事件流 |

## 授权与交付

- 企业只能查询和管理本企业申请、授权与订阅。跨企业访问返回不存在或拒绝访问。
- 产品维护与申请审核只能由有数据管理权限的平台运营方执行。
- 字段按授权白名单输出；线路、指定运单、主体、期限、产品版本和服务方式均在后端核验。
- 调用凭证按散列保存，仅开通或轮换时返回一次完整值；列表与审计不返回完整凭证。
- API、文件与授权报告共享同一授权日额度；订阅另有自身额度。失败调用记录原因，不占成功调用额度。
- 风险事件流每60秒获取授权快照，每次快照计入额度；额度或授权失效后停止。
- 文件提供产品配置的 CSV 或 JSON；授权报告提供 Markdown。链路报告仍需明确获授权运单号。
- 日额度按 UTC 日期重置，页面显示该口径。

## 数据来源的实际边界

当前输出使用平台已登记的可授权业务数据。铁路舱位、港口吞吐、外部船舶能力、公共行业信用等数据尚未接入，产品详情列为后续来源。

未登记信息返回空值；当前运力状态依据有效已发布供给，实时剩余舱位、紧张或饱和状态须接入库存数据后提供。所有测试标记业务不进入对外数据产品。产品中的示例明确标注为字段格式示例。

## 验收证据

- `npm run build`：API 类型检查、Vue 类型检查与 Vite 打包通过。最终兼容修复后的前端构建也通过；保留现有公共依赖包体积提示。
- `npm run test:data-service`：9组通过，覆盖权限、五产品目录、申请审核、跨企业隔离、脱敏、指定运单核验、通道计量、画像、风险事件流、文件、报告、共享额度、轮换、撤销、未生效与到期。
- 原 Phase 8 API 回归：7组通过，企业只读产品目录权限按本次需求更新。
- 浏览器：企业提交申请、平台审核、查看获授权范围；临时订阅查询与调用记录；目录搜索重置；产品字段说明；场景产品授权状态；760px窄屏无页面横向溢出。最终检查未捕获浏览器错误。
- API 和浏览器验收创建的临时业务、申请、授权、订阅均已清理。原有业务保留。

## 图片与页面视觉优化

按用户最新要求，页面采用两张用户提供的粮仓、散粮船照片，以及三张 Wikimedia Commons 的港口、筒仓、粮食铁路车厢实拍照片。当前页面已替换先前的生成图片。

- 产品卡片采用左上角小图，浏览器实测108×82px。标题与类别在图片右侧，正文与操作放在下方。
- 产品详情图片缩小为180×136px；场景应用卡片和订阅卡片同步使用小图。
- 页头使用真实粮仓照片与渐变遮罩。搜索区独立位于背景下方，桌面间距20px、窄屏间距16px，搜索和重置保持在右侧。
- 照片转换为 WebP，保持原照片内容；目录提供「图片来源」入口，列出外部作者、原图页和许可。
- 前端类型检查与打包通过。浏览器确认所有照片加载正常、详情入口可用、场景卡片布局正常；当前视口无横向溢出，未捕获控制台错误。
