# 公路车辆错峰运动

8 个已有在途车辆任务分别设置发车、预计结束时间和独立道路几何。公主岭站至鲅鱼圈港采用 3 条高德缓存道路路径，盘锦站至蒲河铁路物流基地采用另外 3 条路径；同一路径上的车辆也按不同时间出发。参考平均速度约为 32.6–46.7 公里/小时。

地图模型直接落在经纬度位置，没有车辆屏幕偏移或拉线。默认视野适配在途车辆，保留“全程路线”按钮查看完成与计划路段。参考时钟按现实时间推进，不会因刷新重新出发、循环播放或自动完成运输任务。后台每 15 秒更新业务数据，前端沿已采样道路路径持续更新模型与方向。轨迹线每 2 秒更新，不重建地图或持续移动镜头。

运动资料只用于明确标记 `BUSINESS_INITIALIZATION`、`INITIALIZATION` 的草稿合同车辆。尚未接入真实北斗定位；一旦任务有实际 GPS/北斗等来源，或合同进入生效状态，参考运动即退出。没有把计算位置写为真实定位回传，原有轨迹和单据全部保留。页面实时位置、车辆详情、预计到达和历史回放使用同一排程依据。历史不显示未来轨迹点，到达后保持终点，业务完成仍由物流企业提交。

每条路径保留高德原始转弯点，再按最长 900 米采样。异常跳跃、超速路径、无效坐标不参与运动；港口累计量继续按实际单据核对，不按运动推算吨数。已有从旧位置计算的定位过期、偏航、停车、延误参考预警不沿用，当前预警重新判断。

`tools/initialize-road-movement.cjs` 默认预览；`--apply` 先做 SQLite 一致性备份，再以事务补充指定的 8 个任务反馈与排程，以及所属阶段的车辆排程。固定审计标记保证重复执行不会重置时钟或覆盖后续运营修改。

备份和排程清单：`docs/acceptance/road-movement-initialization.json`。

验证：`tests/reference-road-motion.test.ts`、`tests/tracking-models.test.ts`、`tools/verify-road-movement.cjs`。
