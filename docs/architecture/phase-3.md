# Phase 3 实施契约

> 2026-10-02 更新：默认模型辅助求解，按已发布运力推荐物流供应商，方案改为指定议价。手动方案创建独立运输需求，无需交易订单；订单来源需求保留原数量限制。详见 [方案供应商推荐与指定议价](../acceptance/planning-directed-suppliers.md)。

## 用户任务和页面

- `/plans/solve` 是唯一求解入口。菜单进入为空表单；需求入口带入上游信息，起讫地址作为地点查询词，用户选择核对真实节点或地图位置。
- 后端求解公路实际路线，以及可用公共线路组成的完整运输方案。允许方式、中转、粮种、装载、容量、到达期限和指定节点/线路共同约束候选。
- `/plans/prices` 管理公共线路、节点及分有效期价格。平台维护，企业只读。每次重算生成新版本，旧版本和价格快照保留。
- 从候选中选择完整方案。分段只用于解释总价、距离和时长；不生成分段报价对象。正式匹配在 Phase 4。

## 路线与计价

- 公路使用高德 v5 driving，策略32真实候选，记录 `AMAP_DRIVING_GENERAL`。没有货车专用授权验证时不声明货车限行导航。
- 路径由后端查询并按坐标、策略、profile缓存24小时；同一查询进行中复用Promise。几何、里程、时长、道路说明及来源时间一并保存，方案区段引用不可变几何记录。
- 2026-10-02 起使用有界联运图搜索：最多3段干线、5000次路径扩展；起点集港范围随起讫距离扩大到200–850km，终点接驳范围200–650km。相距50km以内的站港可用真实公路连接，所有接驳计入中转次数。按公铁、公水、铁水、公铁水组合分别保留候选，最多保存24条；不承诺全国网络全局最优。
- 铁路/水运公开资料与模拟测算分别记录。无实测轨迹时可绘制明确标识的走廊虚线，实际里程继续返回未知；导入核验几何校验类型、GCJ-02范围、端点及长度。水运区分计划航线与历史AIS，不称实时。
- 计价支持元/吨公里、元/吨、元/箱、固定费用；人民币千分位参考单价、整数分金额，数量整数公斤。区段费用分别舍入后求和；中转等待加入总时长。
- 初始0.320元/吨公里是明确标记的开发样例参数。正式部署须由平台维护有效来源价格，不能将样例改标签当生产价格。
- 方案费用/时长为区段之和，候班、作业和接驳纳入总时长。允许多方式时优先在可行联运候选中独立比较可靠性、全程成本和全程时效；同一条路线多目标最优时合并展示。未知费用不参与成本最优，不承诺实时运力或班期已核实。
- 可选 DeepSeek 辅助规划仅向模型提供地区级起讫位置及公共线路目录。模型只能提出已收录线路ID，后端检查白名单、衔接和业务约束；模型不可用时继续本地图搜索。记录与求解结果关联的 AgentRun/AgentResult，历史读取重新校验方案访问权限。

## 地图交接

- 角色：方案比选地图。低饱和真实高德在线底图。
- P1：当前候选/选中区段，6px；P2：同方案其他区段4px；P3：起讫/中转节点；普通底图在最低层级。
- 公路蓝色实线，铁路紫色长虚线，水运青色短虚线并配文字图例。无实测几何但有测算走廊时明确显示“走廊示意”；两者均缺失时只显示节点。
- 点选区段/地图线双向选中；节点点选显示名称与坐标来源；适配全程、缩放、拖动、图层开关。
- 表单在上，地图与方案面板在下。显示目标推荐和可展开的其他路线，默认只绘制当前候选；无持续动画，卸载时销毁地图。
- JSAPI使用公开JS Key及服务端安全码代理；REST Key与安全码仅本地环境，不进入前端构建或API业务响应。

## 数据权限与可靠性

方案默认所属企业范围，平台可只读查看全局。平台/物流方可独立求解但不能代贸易方选择；跨主体重算拒绝。关联需求字段和运输约束服务端复核，求解期间需求变更返回409。

平台公共主数据维护有权限+主体双重校验，节点坐标变更使关联线路待核验。参考价相同线路和粮种的有效期不得重叠；历史方案使用价格快照。变更和审计在同一数据库事务内。
