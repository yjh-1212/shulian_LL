# 辽粮智运智能体中心

根据用户提供的 `AI_codex.docx` 和辽粮智能体图片完善现有系统。入口为业务页面右下角图片，独立页面为 `/agents`。

## 页面与业务

- 首页、智能体广场、历史对话；保留当前账号与返回业务系统入口。
- 六种能力：联运方案求解、智能问踪、ETA延误预测、港口拥堵分析、环境异常分析、单据识别与复核。每项提供输入指南、使用方法和可填写的示例问题。
- 联运对话先提取货物、地址和运输时间，使用已核验节点或高德定位匹配地址。只有地区参考定位时必须重新确认实际装卸点。明确显示暂填的发运与到达时间。
- 需求上下文保留源需求版本、货物、数量、装载与运输约束，求解器再次校验。直接输入可以修改确认字段。
- 确认后调用现有正式求解器。模型只建议已收录通道；网络连接、道路接驳、参考费用和业务约束由后端校验。推荐按本次候选动态计算，同一路线同时最优时合并。
- 结果包含文字、费用比较、不同运输方式的地图图层、分段与可展开费用明细。地图沿用原有道路几何、铁路和沿海运输走廊。公开参考通道的班期、报价和轨迹限制继续显示。
- “查看更多路径推荐”携带实际 `planRunId` 进入原有方案页面，继续选择物流供应商和发布。
- 问踪、ETA、态势与单据分析读取已授权业务对象；没有可靠来源时显示依据不足。单据支持 PNG、JPEG、PDF、XLSX，8MB上限；提取值和人工复核值分开保存。

## 权限与可靠性

`AgentConversation` 同时绑定用户和企业，`AgentTurn` 保存问题、结果引用及请求编号。历史记录、详情、消息、求解和停止接口都按本人账号校验。平台和同企业其他账号也不能读取个人对话。

每次打开历史记录和调用模型前重新校验业务上下文；旧结果中的运输任务和方案必须仍可访问。授权业务数据可按用户许可发送至已配置的模型服务，凭据不进入模型事实或浏览器。

同一请求编号重试返回已保存结果，不重复产生聊天消息和求解。每账号同一时间只允许一项中心分析。停止操作中断模型等待，网络共享道路查询结束后停止后续求解；已生成方案进入保存阶段后完成保存。失败保留输入，重试区分对话和求解动作。
