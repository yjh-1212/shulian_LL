# Phase 7–9 设计与实现

## 范围与业务约定

以开发设计规范第21–23、37–38节及需求规格说明为依据。沿用 Vue 3 / Element Plus、白色顶部导航、红色主色 #e52b2f、灰色辅助文字、4px间距基准及现有字体。账单详情并列比较“合同约定—实际执行—本次费用”；账单、对账、结算及数据目录、授权、订阅、专题各使用独立路由。签章和司机端保持浏览器模拟；精确地址匹配按用户要求暂缓。

## Phase 7

`ForecastService` 以任务权限为入口：实际 ARRIVE 事件优先；有近期位置、可验证几何、足够合理速度样本时估算当前区段剩余时长和参考区间；否则仅在本企业同起讫、同方式且至少3次完成执行记录可用时使用历史时效。轨迹过期、偏离参考路径、无可靠铁路时效会显示数据不足。后续区段无衔接事实时不给最终 ETA。模拟数据明确标注，规则结果不代替执行事实。

港口与环境记录保存来源、观测时间、有效期、关联节点/范围、风险等级及明确提供的等待分钟。高德天气按节点行政区校验后接入，天气类别不直接伪造延误分钟。后台每60秒扫描最多200项活动任务；缓存60秒，并在状态、位置和事件变化后重算。人工“重新预测”即时刷新。风险持久化为 NEW / ONGOING / RECOVERED，完成或终止业务不保留活动风险。每任务保留最新100次预测。

智能助手继承 API 权限和企业范围。AgentRun记录调用、状态、提供方、耗时及失败，AgentResult记录解释、结构化依据、质量、来源和服务器生成的业务链接。智能体无业务变更工具。联运求解调用原正式求解服务，仍需人工选定候选方案。模型按当前授权对象的摘要提供分析，默认关闭外发，页面勾选后使用 DeepSeek；故障保留规则分析。历史结果读取时重新核验权限。

单据解析在独立限时、限内存子进程运行；图片使用本地 Tesseract chi_sim/eng，文本PDF使用PDF.js，XLSX使用ExcelJS。上传最大8MB，PDF最多10页，Excel最多10表、2000行、100列，图片最多2000万像素，输出文本最多3万字符。文件签名校验，拒绝HTML伪装。原文件保存在数据库；识别字段缺失、失败或不确定均需人工复核。复核保存独立不可覆盖版本，不修改任务签收数量。

## Phase 8

账单由关联承运方创建，选择生效合同下已完成且有实际签收量的任务。`BillTask.taskId` 唯一锁定有效账单范围，作废才释放。贸易方不见草稿。整数分金额与整数公斤参考量避免浮点累计；唯一货量按区段汇总最大值，防止联运区段重复累计。

状态：DRAFT → SENT → CHECKING / DISPUTED → RECHECK → CONFIRMED；撤回回DRAFT，作废VOID。每次变更保存 BillVersion 不可覆盖快照。差异只能由贸易方提出，承运方说明并调账生成新版本，贸易方最终确认才建立唯一Settlement。平台有只读权限。

线下结算结果须附本方上传凭证；另一商业主体确认。requestKey幂等重试、金额上限、待确认记录互斥和乐观版本防止重复支付留痕。支持 PARTIAL、EXCEPTION、SETTLED；金额全部确认后账单归档并在合同履约汇总展示。模拟测试不调用支付渠道。

数据产品登记元数据、数据集、字段、负责人、覆盖、服务方式及使用条件；变更形成新版本并回到草稿，旧授权即时停止。业务明细只允许OWN，本企业主体过滤；指标允许OWN或无私有明细的AGGREGATE；线路仅允许PUBLIC且主数据质量VERIFIED。输出排除测试业务和联系人等敏感字段。

授权记录主体、目的、审批依据、字段子集和期限。API凭证仅首次显示，数据库存SHA-256摘要和前缀，使用X-Data-Key请求头，禁止URL传参。轮换、暂停、撤销、过期、停用主体、产品改版均即时阻断。成功/失败均有DataCall，日限额含并发中的调用。文件支持CSV/JSON，CSV防公式注入。专题应用组合已有订阅，每次查询继续执行权限与限额校验。

## Phase 9

14个迁移部署并进行独立新库、重复seed、正式初始化测试。真实公路—铁路—公路候选串联需求、竞价、议价、签章、联运任务、司机执行、跟踪和费用闭环；签署与线下凭证均使用开发模拟数据。另行验收跨企业/角色/API权限、AI上下文、上传安全、审计、网络恢复与浏览器持久化。

轨迹详情保留总量与最新2000点窗口，列表每任务最多500点；地图复用已有生命周期、MarkerCluster、方式图层与数据断点，不为铁路节点生成伪实际轨迹。性能报告为本机开发数据库实测，不是生产容量承诺。

Docker多阶段构建、双站点Nginx、同源API代理、SQLite数据卷、健康检查和迁移入口已提供。生产初始化不导入开发账号/订单/任务。数据库VACUUM INTO备份附SHA-256和迁移清单，恢复只写新文件。当前主机没有Docker运行时，容器构建及TLS上线须在目标部署主机验收。
