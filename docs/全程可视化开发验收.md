# 全程可视化开发验收

更新日期：2026-10-03。

## 页面与业务

- 全程可视化保留「全程跟踪」「专题视图」，高德地图铺满工作区，查询及运单列表悬浮于左侧。
- 运单来自合同转换的联运服务，显示发货人、货类、数量、起终点和阶段进度。全程支持运单／合同号、发货人、货类、吨数区间、起终点、进度联合查询；专题支持公路、水运、铁路分类及车牌、船名、MMSI 查询。
- 查询条件应用后每 15 秒更新，保留地图视角；隐藏页面及轨迹回放时暂停轮询。
- 在途任务使用 34px 车辆、船舶、列车模型，模型位于当前坐标，按行进方向旋转。姓名标签仅在悬停、聚焦或选中时显示，预警使用小角标。
- 同一片区域的模型重叠时显示数量，点击放大后分别查看。在全程缩放下避免展开所有车辆大标签。
- 任务、阶段或整个运单完成后，只保留对应位置小点及历史轨迹；同方式、同目的地的完成任务合并小点。真实数据断点或异常速度之间不连线。
- 点击在途模型、完成小点或港口打开运输过程、位置来源、时间、附件、预测和预警。暂无定位的任务可由专题列表打开详情。
- 运单预警自动显示地图卡片；打开要素详情后在弹窗内显示预警。

## 轨迹回放

- 选择运单后点击「轨迹回放」，统一时间轴同步播放每辆车、每个船次、铁路任务。
- 支持播放、暂停、重新播放、拖动时间及 1×／2×／4×／8× 速度，可勾选单独要素或全部选择。
- 发车／发航之前不显示模型；完成之后收成小点。轨迹逐步绘制；数据断点保留，不把缺失时间插值成正常运行。
- 回放弹窗的坐标与时间跟随播放，运输状态、单据和预测显示当前业务记录，并明确说明。

## 港口数量与身份

- 港口显示单据确认的集港量、目标量、已发船量和分批／全部发运状态，仓库及铁路货场不显示大集港数量标签。
- 散货须有磅单号、毛重减皮重、过磅附件与签收依据；重复磅单、净重不符、缺少称重依据或超量回传排除累计。
- 集装箱同时核对唯一箱号、每箱净重、设备交接单、过磅依据和签收单。箱号按区段去重，计划分配量不当作到港实收量。
- 司机端集装箱及散货均支持回传磅单、毛重、皮重。净重须与回传数量相符。
- 水运发运统计落在起运港，两艘船的分批量合并为港口发运量；不累加同一批粮食经过不同运输方式的重量。
- 系统管理的船舶档案维护所属物流企业、船名、航次、MMSI；水运阶段按本企业选择，AIS 接入验证对应航次 MMSI。
- 企业仅查询关联合同的运单、任务与附件；平台全局查看。司机不能访问管理端运单接口。

## 模拟与接入边界

| 运单号 | 场景 |
| --- | --- |
| YDDEMO20261003ROAD | 锦州至营口港，一辆已完成、两辆在途，过磅确认与作业预警 |
| YDDEMO20261003WATER | 公路及铁路集港已完成，两艘船错开发航，沿海位置与 ETA |
| YDDEMO20261003RAIL | 已完成公路集运，铁路在途、长春节点与编组作业预警 |
| YDDEMO20261003DONE | 全程已完成，11 辆车、2 个船次、1 个铁路任务的同步历史回放 |

- 样例均为测试业务。缺少历史轨迹且开启开发模拟时，根据已知端点、参考路线与执行时间补充模拟历史；不写入真实定位或合同事实。真实定位即使只有一个点也优先保留。
- 明确登记的北斗／AIS 样例按任务时间动态移动，公路沿保存的高德道路几何运行，水运沿参考沿海航路运行。铁路按节点与参考铁路走廊模拟。
- 锦州至营口港道路参考取自高德 Web 服务，218.138km，1627 个几何点，保存于 `tools/fixtures/tracking-port-road.json`。道路路径是参考依据，车辆定位仍标注为模拟。
- 已完成历史用完成阶段、司机回传时间确定终点；在途补充轨迹同时提供模拟 ETA、范围与作业影响预警。
- 页面和来源字段均区分模拟数据。关闭模拟或生产环境不生成补充位置、轨迹及模拟预测。北斗、AIS 的实际设备服务尚未接入。
- 实际定位沿用 `/api/tracking/tasks/:id/positions`，铁路沿用节点事件接口；支持 GCJ-02／WGS-84，实际 ETA 沿用现有预测服务。

## 验证

- `npm run build`：后端 TypeScript、前端 Vue 类型检查与生产打包通过。
- `node tests/tracking-workspace.cjs`：10 组数量校验、联合查询、企业隔离、船舶身份及定位接入测试通过。
- `node tests/tracking-playback.cjs`：5 组时间插值、数据断点、历史补充、真实定位保护、公路沿道路运行、港口统计和全程回放测试通过；核对集港完成早于发航、铁路最近节点与在途位置。
- 浏览器验证：完成任务无车辆大标签；两辆在途车点击放大后独立展示；两艘船位置不同；铁路模型、坐标与预警；港口过磅依据；14 项回放选择、速度、暂停、拖动时间。
- 结果：`acceptance/tracking-workspace-api.json`、`acceptance/tracking-playback.json`。
- 最终截图：`acceptance/tracking-models-road.png`、`acceptance/tracking-models-water.png`、`acceptance/tracking-models-rail.png`、`acceptance/tracking-replay-completed.png`。
