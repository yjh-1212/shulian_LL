## 页面和权限

合同履约及档案列表会读取具有明确 `BUSINESS_INITIALIZATION` 来源、`referenceOnly: true` 的合同过程资料。普通真实草稿不会获得这一列表例外。初始化合同及资料只能查看；提交、编辑、变更、正式归档和签署继续被后端阻断。

详情中可查看付款计划、收款跟进、计量回传、费用、调整提案、阶段过程及原件清单。已有真实生效合同继续读取原来的付款登记、收款确认、修订、凭证及归档数据，操作规则保持不变。

档案按当前企业的 `packageId + entityId` 查询。平台只看到平台自身的档案版本；贸易方与承运方只看到各自版本，不返回其他企业的私有归档快照。平台列表为 10 份履约、6 待归档、4 已整理档案；贸易方 A/B 和承运方 A/B 各为 5 份履约、3 待归档、2 已整理档案。无关企业不能查看这些合同。

“已整理档案”表示生成过程资料的归档快照，仍标记 `UNVERIFIED_BUSINESS_RECORD`，不代表合同已经签署、付款完成或原件已经取得。

## 运行和验证

node tools/initialize-contract-processes.cjs --apply
node tests/contract-initialization.cjs
