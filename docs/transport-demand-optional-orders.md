# 运输需求与交易订单的可选关联

## 操作

运输需求管理 → 新建运输需求。交易订单为选填项：

- 直接填写：选择粮种、填写规格、运输数量、地址、时间及联系信息，保存为独立需求草稿。
- 关联订单：选择本企业的有效明细，带入订单粮种、规格、可运输数量、提货地址和已有联系方式。目的地址和时间由企业确认填写。
- 取消关联：保留带入的货物和运输条件，继续手动修改。保存后释放此前占用的订单数量。
- 更换订单：草稿可重新选择明细；旧订单释放与新订单占用在同一事务中提交。订单关联时货物信息以订单为准。

已发布的需求先撤回，已确认承运的需求须先处理承运确认。保存失败保留填写内容；本地未保存内容按登录账号与需求 ID 分开存储，七天内重新打开时可恢复。
