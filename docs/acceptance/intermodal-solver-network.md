# 多式联运求解网络与 DeepSeek 辅助规划

> 供应商与发布流程已更新，见 [方案供应商推荐与指定议价](planning-directed-suppliers.md)。模型辅助默认开启；手动方案无需交易订单，选择供应商后进入指定议价。

日期：2026-10-02。

## 结果与规则

解决只有公路候选的两个原因：公共干线目录太小，固定200km接驳与完全相同节点的衔接限制漏掉内陆粮源集港路线。

- 公共目录从3条扩充到22条，新增17个通过高德定位的站港节点。原有平台修改通过幂等导入保留。
- 根据实际起讫坐标，搜索铁路集港、铁路干线、沿海船运和公路接驳；接驳全部计入中转及总时长。
- 分组合保留候选，优先从可行联运方案中选择可靠性、成本、时效目标的最优路线。若同一路线同时最优则合并标签；其他可行路线仍可切换、查看分段并发布匹配。
- 到达期限、指定线路/节点、粮种、装载、运力、中转与允许方式仍参与后端校验。没有可行联运时给出原因并保留公路备选，不制造铁路或海运区段。
- DeepSeek 可通过页面勾选开启，只辅助选择目录中的通道；真实路线、价格、船期不能由模型自由生成。API故障或返回无效线路时降级为本地求解。

## 测算与数据边界

- 公路几何、里程和基础行驶时间来自高德，仍需核对货车限行。
- 铁路/海运实际轨迹未取得时绘制走廊示意，不显示虚构实际里程。公开时效存在时沿用公开口径，否则明确标记按区域节点估算。
- 价格、候班、装卸、箱具服务和可靠性均为模拟测算。铁路示例为约0.08元/吨公里、最低35元/吨；船运按线路示例吨价；可靠性为区段评分均值减每次衔接2分，不是历史准点率。
- 散粮装拆箱费整条路线仅计一次。所有费用在区段快照中逐项保存并汇总，实际报价由后续供需大厅整体承接确认。
- 模型仅接收省市、四舍五入到0.1°的坐标、允许方式、装载形式和公共线路名称/ID；不发送订单号、详细地址、联系人、数量或补充说明。
