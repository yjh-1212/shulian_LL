# Phase 5 模拟合同与联运执行验收

验收日期：2026-10-01。用户确认采用模拟电子签章、电脑浏览器模拟司机小程序。

## 已实现

- 合同模板、签署、履约、档案四个独立页面；平台维护并发布不可变模板版本。
- 承运确认生成主合同与附加合同包，保存成交、企业、路线、模板、条款正文和 SHA-256 摘要。
- 提交、承运方确认、退回、撤回、拒签、新版本重新起草；A 模式双方签主合同并确认附加合同，B 模式平台额外签附加合同。整包完成才能派发运输。
- 条款变更与协商终止重新走完整签署，原文、拒签、签署记录不覆盖；未结束运输阻止终止。
- 履约统计按末段已完成任务的卸货量计算，显示异常、数量偏差及到期/到达超时提示。档案导出包含本次成交议价、各版本签署、运输事件及附件索引。
- 联运组织区分一单制和传统模式；前者生成联运运单编号。区段路线来自所选方案或人工组织，同一区段派发量不可超过合同量。
- 本企业车辆与有效司机选择，公路任务由司机执行，铁路/水运任务由 PC 操作。区段间装货受上一段已交付量限制。
- 散改集批次、多车到货净重、箱内多车来源、封条、船舶航次，以及任务关联批次/箱号；累计到货、装箱和派发均做数量校验。
- 司机独立网址 `http://127.0.0.1:5174/`（原开发入口 `/driver` 自动跳转）：接单、信息有误退回、到达装货、装货凭证、发车、位置记录、到达卸货、卸货、回单、完成；异常上报及调度处理。
- PNG/JPG/PDF 单据最大 8 MB，服务端验证文件头及任务归属；事件去重、状态顺序控制、审计记录。
- 司机与 PC 使用不同 JWT audience 和刷新 Cookie，允许同一浏览器同时登录；司机不能访问 PC API。

## 当前范围

- 所有签署均明确标为模拟，不提供真实电子签章证书、短信身份核验或签章平台回调。
- 司机端为浏览器实现，按用户要求未创建微信小程序构建或发布流程；浏览器位置仅在司机主动操作并授权后记录。
- 模板支持正文、版本、生效时间和 A/B 规则；可视化条件条款编排、签署顺序配置与独立法务审批尚未实现。
- 当前变更支持结算、作业要求、平台费及截止时间；成交数量、成交运输价和承运主体保持来源确认快照，复杂商务变更需后续扩展。
- 一单制已提供运单编号、业务快照及区段任务关联；独立运单版式导出、双方运单确认和运单变更版本管理尚未实现。
- 散改集保存磅单编号和来源分配；批次级磅单图片及装箱作业图片专用附件入口尚未实现，任务单据支持上传下载。
- 执行事件具备任务、阶段、来源、操作者、位置及时间记录；尚未提供 GS1 EPCIS 标准接口、GPS/AIS/铁路实时接入或后台推送通知。
- 列表当前读取最多 500 条并在前端筛选；生产规模分页和正式 PDF 合同/档案打包需继续扩展。Vite 仍提示既有主包较大，本轮未调整公共包拆分。

验收数据均为开发模拟，不代表真实货运、运价或履约事实。


## 2026-10-01 司机模拟界面修订
