# 智能体中心浏览器验收

2026-10-03，在本地开发环境使用粮食贸易商账号操作。

| 操作 | 结果 |
| --- | --- |
| 点击业务页面右下角辽粮图片 | 打开独立智能体中心，六张能力卡片均可见 |
| 从联运求解输入盘锦站到广州国际港站、100吨玉米、散貨 | 显示可编辑地址与运输条件，并说明暂填时间 |
| 打开起运地址选择器，选择核验节点并确认 | 保留节点定位，可以查看高德地图 |
| 确认并求解 | 生成15条可行候选；推荐公铁和公水，同一路线的可靠性与时效最优合并显示 |
| 切换成本推荐 | 地图同步显示公路接驳和沿海水运走廊，保留示意说明 |
| 点击查看更多路径推荐 | 进入同一实际方案的求解页面，显示供应商推荐与发布按钮 |
| 返回并刷新对话页面 | 地址确认、方案结果和实际方案链接仍可读取 |
| 从左上角切换到单据识别，搜索本人运输任务 | 可以选择任务并显示上传识别工作区 |
| 上传开发样例PDF | 提取运单号、货物、起讫地点、日期、承运主体和5吨数量 |
| 勾选核对并保存 | 显示已复核状态，结果保存在对应任务单据记录中 |

截图：`agent-center-home.png`、`agent-center-route-map.png`。自动化功能与权限结果见 `agent-center.json`、`agent-center-analysis.json`。
