# Phase 3：联运方案与公共线路价格验收

日期：2026-10-01。环境：Windows、Node 24.17.0、SQLite、真实 Nest API、Vite 与 Edge。该阶段完成开发验收，生产业务数据接入限制见文末。

## 已交付

- **方案求解** `/plans/solve`：菜单进入空白业务表单；从运输需求详情进入时带入订单、粮种、数量和运输约束，锁定来源字段，要求核对真实起讫位置。
- **真实地图**：高德 JSAPI 在线底图、POI 搜索、节点/地图选点、真实道路候选、路径与区段联动、图层开关和全程视角。当前候选绘制在地图上，其他候选可点击切换。
- **求解规则**：运输方式、粮种、装载、运力、指定节点/线路、中转次数、到达期限，以及成本/时效/综合排序。总距离、时长和费用均由区段汇总。
- **版本与选择**：重算新版本、保留旧结果与价格快照、求解记录、贸易企业选择完整方案、并发版本冲突校验和审计。
- **公共线路价格** `/plans/prices`：平台维护节点、线路、有效期参考价及铁路/水运几何；企业只读；搜索、筛选、分页、所选导出、编辑冲突和有效期重叠校验。
- **数据与接口**：三次增量迁移，六个真实 POI 定位节点，24 小时数据库道路缓存，幂等初始化，OpenAPI 0.3.0 快照。

## 本轮修复

- 数量输入步长与三位小数一致，必填项分别提示；日期控件通过“确定”提交选择后再开始求解。
- 表单变更状态可正确清除；同页切换求解记录保留未保存提示。
- 空运输方式筛选不再发送无效枚举值，线路列表可正常加载。
- 需求详情的方案入口不放开原有撤回、取消、删除权限。
- 代理使用有效登录会话、当前地图权限与固定上游路径；退出后旧地图 Cookie 不可继续访问。

## 数据与服务边界

1. 公路来源是高德正式通用道路服务，保存 `AMAP_DRIVING_GENERAL`；没有验证货车限行授权，不当作货车专用导航。
2. 六个节点来自真实高德 POI 定位。节点存在不代表货运装卸能力或实时运力已经核实。
3. 暂无可核验的正式铁路/水运业务线路几何。平台可维护有依据的线路并导入 GCJ-02 坐标；没有几何的区段明确标注缺失，只展示节点。
4. 初始 0.320 元/吨公里为开发样例参考价。正式使用须维护真实价格、班期、容量与来源；当前行驶时长未包含司机休息、实际船期和装卸排程。
5. 候选采用有界搜索：每端接驳检索 200km、最多 3 段已维护干线、最多输出 6 个方案，不保证全国网络全局最优。
6. Phase4 才实现报价、议价、承运确认与正式匹配。当前选择保存完整方案，没有生成分段报价或执行任务。
7. 已升级兼容的 NestJS、Axios、Vite 等安全补丁。最终 [npm 审计](phase3-npm-audit.json) 仍报告 **3 项 high、2 项 moderate**：`deepmerge-ts` 及其 Prisma 配置工具依赖链，和 `js-yaml` 及其 Swagger 依赖链。没有为消除扫描告警而强行升级 Prisma/Nest 主版本。生产发布前须完成这些依赖修复和回归；本轮通过的是开发功能验收。

## 复验

启动 API 和 Web 后运行 `npm run test:phase3`。保留其生成的数据，重启 API，再运行 `npm run test:phase3-restart`。`test:phase3-boundaries` 和 `test:phase3-fresh-db` 可独立执行。密集运行多个套件需遵循登录速率限制，套件之间可间隔一分钟。

浏览器验收使用独立 Edge 配置，不读取个人浏览器数据；截图与结果不包含 Web 服务 Key、安全码或大模型 Key。
