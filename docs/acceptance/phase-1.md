## 已发现并修复

- 退出时复制Express Request导致审计访问不到headers，已改为保留原请求上下文；复测退出后JWT不可用。
- 主按钮文字受到工具栏样式覆盖，已恢复白色主按钮文案。
- 悬浮助手靠近分页，已给分页操作预留空间。
- 开发环境新增账号/主体自动标记测试数据；生产模式拒绝样例账号登录。
- 多选角色控件采用键盘展开完成浏览器验收，确认角色按主体类型筛选。

## 覆盖边界

- 浏览器实测为Windows Edge；没有宣称Safari/Firefox、屏幕阅读器或完整WCAG认证。
- 本次没有生产业务数据、电子签章证书、GPS/AIS或铁路提供方，未执行运输业务验收。
- 高德与DeepSeek密钥尚未使用；不会将待接入状态表述为外部集成成功。
- 第一阶段提供六个基础角色的授权配置；复杂组织树、自动锁定/解锁、资格审核等按系统管理完整需求继续扩展。
- 首屏JS包约1.08MB（gzip约359KB），构建有体积提示，后续模块扩展应按路由拆包与按需组件加载。
- 当前为本地开发部署，尚未完成HTTPS网关、备份调度、多实例限流、生产管理员引导与完整生产安全验收。

## 复验

先启动API与Web，再运行 `npm run test:e2e` 和 `npm run test:accounts`。脚本使用开发账号及独立浏览器profile。登录限流为每IP每分钟8次；密集重复测试可能需要等待限流窗口结束。
