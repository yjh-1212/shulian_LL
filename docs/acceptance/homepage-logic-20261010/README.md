# 首页内容与展示逻辑调整

本机访问地址：http://127.0.0.1:3002/

## 页面组织

导航统一为联运服务、智能服务、数据服务、物流一张图，顺序与正文一致。

- 视频覆盖整个首屏与导航，右下角业务标识区遮挡视频水印。
- 平台简述收为短区域；运输方式和五步业务流程集中在联运服务中。
- 业务流程切换实际系统界面，并提供对应业务入口。
- 智能服务按运输前、运输中、交付时切换问题、说明和入口，六个智能体保留为简洁链接。
- 数据服务按找资源、看态势、查链路切换内容与图片。
- 物流一张图固定使用平台运营预览，直接打开 `/cockpit?view=platform`。
- 服务对象和平台访问入口集中在页尾。

## 素材与数据

首屏继续使用用户提供的 15 秒视频。新增五张产品预览为本机系统中 trader 账号的界面截图，没有创建业务记录。截图中的记录来自现有本机数据，不作为已发生的生产交易证明。

智能问答区域为预先编写的功能说明，界面标注“问答示例”；未调用大模型、提交单据或生成实际问答记录。数据服务复用现有主题图片。首页没有新增虚构运营指标。

## 验证

`npm run build -w @grain/web` 通过。现有依赖和驾驶舱分包仍有较大体积的构建提示。

15 项浏览器检查通过，详见 `results.json`：

- 导航层级与正文顺序。
- 视频覆盖导航、播放控制与水印遮挡区域。
- 四种联运方式、五个业务环节、三个智能场景、三类数据用途切换。
- 页签键盘操作及固定导航下的锚点位置。
- 图片加载、页面布局、浏览器错误与资源请求。
- 首次进入默认 trader 登录及五个业务目标页面。
- 智能场景进入对应智能体，数据服务进入对应页面。
- 物流全景公开入口固定平台运营视角。
- 登录失败重试保留目标页面。
- 减少动态效果偏好、视频失败回退和重新加载。

最后替换联运区默认图片后，另行完成图片加载与视觉复核。全页与板块截图保存在本目录。手机尺寸检查仅针对首页。

本次更新到本机运行服务，未发布腾讯云或 Render。
