# 方案供应商推荐与指定议价

验收日期：2026-10-02。

## 当前业务流程

1. 求解默认调用模型辅助识别已收录的联运通道。页面不展示模型品牌、勾选项或调用状态。模型失败时仍可使用本地联运网络求解。
2. 比较可靠性、成本和时效的实际推荐路线；选择路线后，页面最下方查询物流企业已发布的运力。
3. 可多选 1 至 10 家物流供应商，卡片右上角以红色徽标突出“推荐值”和分数。点击“发布此方案”，弹窗列出全部选定企业、推荐值、完整方案、联系人和响应截止时间，确认按钮为“发布”。
4. 发布保存为一份 `DIRECTED` 指定议价，通过 `MatchRecipient` 记录多家目标企业及运力版本。完整分段方案和推荐依据留存于快照，运输数量只计算一次。发布快照的运输方式来自所选方案。
5. 所选供应商分别报价，只能查看自己的推荐及报价；货主可比较所有报价，最终确认一家整体承运后继续生成合同。重新打开求解记录时保留已发布方案的勾选状态。

手动输入的方案发布时创建独立运输需求，保存粮种、数量、装卸地址及时间，不要求交易订单，也不占用任何订单余量。从已有运输需求带入时保留原订单关联与原数量占用。独立需求支持撤回、编辑、重新求解及取消。

## 推荐规则

只查询有效的已发布运力及正常物流企业。筛选起讫城市或省份、数量上下限、适运粮种、服务时间、装载形式和运输方式。多式联运方案要求整程联运运力，同一企业只展示一条最适配运力。

评分满分 100：路线 40、方式适配 15、价格 20、实际接单记录 15、注册地 10。价格比较已知报价，未知报价不当作免费运输。接单记录统计有效承运确认，不虚构历史订单。企业注册地支持平台维护省市，后端核验行政区并规范名称。

集装箱报价按 20GP 或 40GP 计算；未填写箱数时，分别按 26 或 27 吨/箱估算并显示提示。散粮入箱方案可以匹配声明集装箱运力的企业。整程运力报价供比选，附加费用、真实运力和成交条款在议价中确认。

发布事务再次检查全部企业与运力状态、供应版本、方案版本、源需求版本和响应截止时间。任意一家失效时整次发布失败，不产生部分发布或额外需求。重复提交同一方案和供应商集合返回原发布，选择顺序不影响幂等；更换集合须先关闭原发布。指定议价的详情和报价只对相关企业开放，平台按现有权限查看。

迁移会回填原单供应商指定发布，原接口仍兼容单选参数。完整方案共用一份需求和发布，不开启分量承接。确认一家后，其他报价不能再次确认，避免超额承运。
