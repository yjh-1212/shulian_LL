# 联运求解工作台更新

日期：2026-10-02。

## 页面与业务

- 上方集中输入条件，下方地图左、方案右。右侧支持可靠性、成本、时效排序，切换维度回到首个候选。
- 保留详细地址、粮种、数量、发运/到达时间、运输方式、装载形式、集装箱箱型/箱数和补充要求。
- 移除货物重复名称、多式联运开关、中转开关/次数、优化偏好及指定节点/线路等输入。后台继续执行关联需求已有约束。
- 需求带入保留原始地址，先匹配已定位节点，再做高德地理编码与 POI 匹配。仅定位到区县的地址要求确认实际装卸点。
- 直接输入和运输需求各提供一个盘锦—广州、玉米100吨示例。需求示例实际进入需求管理并占用本企业示例订单余量；同一企业的未过期示例草稿复用。
- 方案卡片显示全程吨价、模型可靠性评分和运输时间。分段卡片显示节点、方式、里程、费用、衔接及作业时间，详情显示费用项目及公开资料链接。
- 不提供供应商列表。选择方案后通过发布表单直接公开发布到供需大厅，运营商后续整体报价。
- 手动方案发布关联本企业同粮种交易订单，原子校验累计运输量、占用订单数量、创建需求、选择方案和创建发布记录。重复提交同一有效发布返回原记录。
- 已发布方案禁止换选；重新发布须先关闭原发布并按需求当前版本重算。发布保留路线和费用快照。

## 公开路线依据

1. [辽宁省政府：蒲河—广州国际港 X8784/3](https://www.ln.gov.cn/web/ywdt/zymtkln/2025041108514451900/index.shtml)，2025-04-11发布。公开资料为2745公里、38小时35分、每周5列；报道货源包含电商和日用品，粮食承运资格及当前班期仍须核实。
2. [泛亚航运内贸航线产品](https://www.panasiashipping.com/contents/Product/14.html)，本次查询确认营口—南沙 IC9 为2天班、7天交货期；锦州—南沙 IC15 为每周3班、7天交货期。未取得具体船名航次、舱位及航程几何。
3. [辽宁省政府：北粮南运通道建设](https://www.ln.gov.cn/web/ywdt/msrd/2025111009010174906/index.shtml)，2025-11-10发布。说明东北粮食通过铁路及辽宁港口南运、铁水联运及散改集的业务背景。

公路使用高德道路路径。铁路、水运采用带来源的走廊示意，分别使用紫色长虚线、青色短虚线，不作为实际轨迹或导航。未知航程里程保持待核验。

## 测算范围

- 模拟干线费率：铁路220元/吨，营口—南沙108元/吨，锦州—南沙104元/吨。
- 示例费用还包括起讫装卸各8元/吨、箱具使用5元/吨；散粮入箱增加装拆箱12元/吨。税费、保险、超期堆存及额外作业待实际报价明确。
- 铁路候班24小时、装卸8小时；IC9候班24小时、装卸12小时；IC15候班28小时、装卸12小时。属于模拟假设，未取得实际订舱及配车承诺。
- 公路参考时效增加每8小时行驶对应4小时休息；初始接驳作业另计4小时。未校验货车限行及实际车队排程。
- 可靠性是模型评分：区段基础分均值四舍五入，减去每次衔接2分。示例公路88、铁路94、IC9为85、IC15为84；不是历史准点率或履约概率。
- 金额、费用项、候班、模式及路径类型存入方案快照，维护参考价或更改模拟参数后旧方案保持原测算。

## 2026-10-02：三种目标生成推荐路线

- 删除可靠性、成本、时效排序标签。后端从满足输入约束的候选路线中分别求解可靠性优先、成本优先、时效优先方案，返回候选 ID、目标标签和选择依据。
- 可靠性按全程评分最高选取，同分时减少衔接；成本在费用完整的路线中取最低，同价时取较快路线；时效包含候班、装卸和衔接时间，取最短全程用时。
- 同一路线在多个目标下最优时合并展示。没有完整费用时提示无法生成成本优先方案；没有可行路线时不显示三种占位方案。
- 保存候选时优先保留各目标最优路线，避免候选数量上限遗漏目标赢家。历史记录按保存的指标恢复推荐，不影响已选或已发布路线。
- 三张推荐卡片同屏展示。选择卡片后联动地图、分段费用与公开发布的候选 ID。
- 验证：API 构建、前端生产构建、`planning-recommendations.cjs` 与 `planning-workspace.cjs`；浏览器验证成本、时效卡片切换地图和分段。
