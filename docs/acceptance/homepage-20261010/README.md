# 首页改版验收 · 2026-10-10

本机预览：http://127.0.0.1:3002/

## 页面调整

- 第一屏使用 `mp4/back_1080p_compressed.mp4`，完整覆盖顶部导航背景。首屏为透明导航，滚动后切换为白色紧凑导航。
- 视频以静音、循环、行内方式播放；右下角使用不透明的“北粮南运 · 全程协同”业务标识区遮挡原视频水印。源视频未修改，发布资源为其相同内容的副本。
- 视频可手动暂停，移出可视区域或切换到后台时暂停。偏好减少动态效果的浏览器默认显示封面，用户可手动播放；视频加载失败时保留封面并提供重新加载入口。
- 首页采用大画面与连续内容分区：平台介绍、四种联运方式切换、业务流程与工作台、六个智能体入口、双驾驶舱预览、数据服务和联运生态。减少重复卡片与边框。
- 保留首次访问默认以 trader 进入平台的行为；新增内容入口沿用该登录流程并转到对应业务页面。驾驶舱仍可独立直接访问。
- 新增封面从用户提供的视频提取；驾驶舱预览由现有驾驶舱验收截图转换为 WebP。本次没有添加数据库记录或虚构业务统计。

## 验证

`npm run build -w @grain/web` 通过。构建仍有项目原有的大文件分块提示。

浏览器共 15 项检查通过，详情见 `results.json`：

- 视频解码、15 秒时长、静音循环与行内播放；视频覆盖透明导航，抽查 1、5、10、14 秒首屏。
- MP4 支持 Range 分段读取：206，正确的 video/mp4 类型及 1,024 字节响应。
- 四种联运方式切换、方向键切换、双驾驶舱预览切换、图片完整加载。
- 手动播放/暂停，离开首屏自动暂停，返回首屏恢复播放。
- 首页在 1920、1440、1366、1024、768、390、360 宽度下检查布局；没有横向溢出，右下标识未越界。手机只检查首页，没有检查驾驶舱手机布局。
- 减少动态效果时默认不请求视频，手动播放可用；视频加载失败后封面和重试可用。
- 实际点击“立即体验”“进入平台”“进入智能多式联运平台”均可进入工作台，首次自动登录返回 trader，接口正常返回 201。
- 数据服务与智能问踪入口正常；独立驾驶舱入口不发起登录请求。
- 登录失败时显示错误，重试后仍进入用户原先选择的数据服务页面。
- 首页未发现脚本异常或资源失败响应。
