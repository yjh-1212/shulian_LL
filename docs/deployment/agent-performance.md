# 智能体加载与问答更新

## 本次修复

- 任务下拉列表改为数据库分页查询，不读取所有任务的轨迹、道路及风险；打开首页和切换智能体时不加载这个列表。
- 首页、智能体介绍、历史对话及运输选项分别加载。历史列表或运输选项失败时，页面仍可使用，并提供对应重试入口。
- 问答先显示已读取的业务摘要，再逐步显示 DeepSeek 回答。方案生成也有进度、心跳和流式说明。
- 修复 HTTP IP / 域名访问下 `crypto.randomUUID` 不可用导致的分析卡住；请求编号保持唯一，并保留重复请求保护。
- 停止操作中断模型连接并保留输入。模型调用超时、响应中断及数据库异常会释放分析锁，不把未完成的模型文本保存为完整回答。
- 单据列表与详情只做轻量权限校验；查看元数据时不加载原件二进制内容。

## 已有腾讯云服务器更新

1. 停止当前 Node.js 项目，用面板或原进程管理工具备份正在使用的数据库、`.local/uploads` 和 `.env.server`。
2. 解压 `liaoliang-agent-fix.zip`，将其中 `liaoliang-server/` **里面的文件**覆盖到当前项目根目录（包含 `package.json` 的目录）。该更新包包含程序和部署说明，不含数据库、上传附件或密钥配置。
3. 用原来的命令重新启动项目，例如 `npm start`，然后在浏览器强制刷新智能体页面。

无需重新导入数据或重置账号；数据库结构和依赖没有改变。本次测试对话保存在本地副本，未写入腾讯云数据库。

`ll_dist/liaoliang-server.zip` 也已更新，适合新服务器完整安装；已有业务服务器请使用上述更新包，保留线上数据库。

## 反向代理

直接访问 `http://服务器IP:8080` 无需另配流式代理。通过 Nginx 时，服务会发送 `X-Accel-Buffering: no`；如果面板忽略这个响应头，可在代理到 Node.js 的 location 中添加：

```nginx
proxy_buffering off;
proxy_read_timeout 240s;
```

仓库中的 `deploy/nginx.node.conf` 已为智能体接口提供独立配置。已有 Nginx 设置请保留自己的域名、证书和端口，再合并对应 location。Render 使用最新版程序即可，不需要填写 Nginx 配置。

## 检验结果

验证环境：本地 Node.js 服务、打包数据库的独立副本、可见 Edge 浏览器、非安全 HTTP 域名及系统配置的真实 DeepSeek 服务。

- 首页在故意延迟上下文和历史接口 2 秒的情况下，约 0.4 秒显示；六个智能体切换约 0.45–0.51 秒。
- 问踪、ETA、港口、环境、单据的真实分析成功；问答能在最终结果前显示业务摘要和模型内容。
- 浏览器中一次问踪约 0.9 秒显示业务摘要，4.8 秒完成。
- 公主岭站至鲅鱼圈港的条件整理和已收录铁路通道求解成功，生成 1 条候选；重复提交相同请求未重复写入对话结果。
- 停止后重新发送、账号隔离、任务搜索、断流检测、分析锁释放，以及服务器运行回归检查通过。

这些时间是本地实测，腾讯云表现还取决于服务器性能及到模型服务的网络连接。真实问答发送账号授权范围内的业务信息到配置的模型服务，按服务商规则计费；费用不会由程序自动充值。

真实回归测试（会调用配置的 DeepSeek，并将对话写入独立副本）：

```powershell
$env:AGENT_TEST_PASSWORD='已配置账号密码'
node tests/agent-performance.cjs
```

流式和失败恢复的本地单元测试：`node tests/agent-stream.cjs`。两者均需要先完成构建。
